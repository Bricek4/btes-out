# Agent Studio UI 设计基线

## 产品与页面目标

Agent Studio 是面向开发者、项目负责人和运维人员的桌面优先工作台。核心任务是导入代码项目，选择模板与模型，发起文档或截图工作流，处理人工确认，最后预览、下载和分享产物。界面要让长任务状态、下一步操作和异常原因始终清楚，同时保留高密度信息的可扫读性。

前端使用 Vue 3、TypeScript、Vite 和 Agent Studio 自绘 SVG 图标。运行时不加载外部字体、图标、图片或设计站资源。

## 灵感结论

- Mobbin：采用“先展示完整流程，再展开单个能力”的信息层级；任务入口聚焦一个主动作，状态与详情逐层展开。
- Godly 当前跳转到 Recent：采用紧凑的分类导航和模块化内容网格思路。它的瀑布流、强图像和多色内容不适合生产工作台，因此不复制视觉外观。
- Detail Design：采用原生 label 关联、扩大点击区域、明确焦点、轻量状态反馈和可发现的快捷操作。动效只用于解释状态变化，并支持 `prefers-reduced-motion`。
- awesome-ui-design：采用筛选状态写入 URL、详情在上下文浮层展开、清晰空态和选择后即时反馈等交互原则，不复制其品牌、配色和页面构图。

## 视觉规则

### 配色

- 页面底色：`#f3f3fb`，允许极浅的冷紫与薄荷色环境光。
- 主文字：`#171726`；正文：`#5c5d6e`；辅助文字：`#747486`；占位与说明文字：`#9091a2`。
- 品牌主色：`#6558e8`；悬停/按下：`#4f43cf`；浅底：`#eeecff`。品牌色只用于主操作、选中导航和智能能力。
- 成功：`#168b76` / `#e8f8f4`；警告与待确认：`#9b681a` / `#fff4d8`；危险：`#c8425a` / `#fff0f3`；进行中：`#4d63cf` / `#edf0ff`。
- 状态前景色与浅色背景必须成对使用。关键信息同时使用文字和图标，不能只依赖颜色。
- 面板使用半透明白和 8% 至 15% 的冷灰描边，核心信息不能依赖透明度才能阅读。

### 品牌主图标

- 品牌主图标使用独立的 `BrandMark.vue`，不再复用模型能力图标。
- 符号为分离顶点的折带 A：两条实心斜带和一条短横桥组成，表达 Agent 与工作流连接。轮廓优先于装饰，不增加星芒、中心圆点、齿轮或外围射线。
- 32px SVG 画布中的符号范围为 x=5 至 26.4、y=7 至 25；两条斜带顶部保留清楚的间隔，横桥使用浅紫色区分层次。24 至 27px 显示时仍保留足够留白。
- 容器为 36px 石墨紫色方牌，圆角 11px；仅使用一道内侧高光和短距离低透明阴影，不使用浮光圆点或发光光晕。
- 侧栏、收起侧栏和登录页使用同一个组件与比例；移动端操作坞不重复显示品牌牌。符号为装饰元素，读屏由相邻品牌文字提供名称，不能进入键盘焦点。
- 收起侧栏的展开按钮与主图标保持至少 5px 的视觉间隔，键盘焦点外环不能穿过品牌轮廓。

### 功能图标

- 全部使用 Agent Studio 自己的内联 SVG 图标集，不使用通用图标库、Emoji 或远程资源。图标由 `src/lib/icons.ts` 统一定义。
- 图标语言采用开放边框、流程节点、短切角和偏移的双层结构，表达“输入、流转、确认、交付”。外轮廓以 24px 画布中的 4 至 20px 区域为基准，内部节点保持 3 至 4px 间隔，避免小尺寸粘连。
- 导航图标为 18px，默认描边 1.8，选中描边 2；按钮图标为 15 至 16px，描边 1.8；状态图标为 13 至 14px，描边 1.9。
- 图标与文字间距 7 至 9px；独立图标容器为 32、40 或 42px，并保持光学居中。
- 相同语义始终使用相同图标：项目使用 `FolderKanban/PackageOpen`，任务运行使用 `Activity`，模板使用 `Blocks/FileText`，模型使用 `Sparkles`，登录档案使用 `KeyRound/UserRound`，安全使用 `ShieldCheck/LockKeyhole`。
- 工作流类型使用固定图标：项目文档 `FileText`，用户手册 `BookOpenCheck`，HTML `Code2`，截图 `ScanLine`。
- 状态图标全部专门绘制：排队为开放队列框和三个错位条目；运行为断开的流转框和中心节点；暂停为开放框内的双停顿条；审批为分叉菱形和中轴确认点；成功为开放交付框和延伸勾；失败为边框内的交叉断路；取消为被切断的流程节点。
- 破坏性动作不用品牌色；错误提示使用 `TriangleAlert`，空态使用与场景对应的线性图标和浅色容器。

### 按钮层级

- 每个视图最多一个高强调主按钮，用于新建、确认或继续；使用品牌渐变和白色图标文字。
- 次按钮使用白色背景、细边框和深灰文字，用于刷新、测试、上传和返回。
- 文字按钮只用于卡片内低风险操作；危险操作使用红色文字和浅红背景。
- 纯图标按钮必须提供 `aria-label` 和悬停背景，点击区域不小于 34px；紧凑产物操作可缩至 27px。
- 禁用态降低透明度但仍保留文字对比度，不移除标签或图标。

### 状态与反馈图形

- 空态由 40 至 44px 场景图标、标题、说明和可选主动作组成，避免仅显示一行“暂无数据”。
- 错误条使用危险色 `TriangleAlert`，错误正文保持可选择文本，关闭按钮位于尾部。
- 加载状态使用旋转的 `LoaderCircle` 并保留动作文字；成功 Toast 使用 `CircleCheck`；等待人工确认使用 `CircleAlert`。
- 状态标签保持胶囊形，图标在前、文字在后；运行图标可以旋转，其他状态不做持续动画。

### 字号

- 页面标题：桌面 42px 上限，移动端 31px，字重 700 左右。
- 模块标题：16px；卡片标题：12 至 14px；正文：11 至 13px。
- 辅助标签：9 至 10px，使用更高字重和适量字距；不得用低对比度承载关键状态。

### 间距与圆角

- 基础间距单位 4px；常用间距为 8、12、16、24、32、40px。
- 控件最小高度 38px，主要按钮 44px，桌面导航项 44px，移动端导航项 50px。
- 小控件圆角 10 至 12px，卡片 17 至 18px，主容器与浮层 21 至 26px。
- 阴影保持低对比，只表达层级；悬停最多上移 3px。

### 布局

- 1280px 以上：悬浮侧栏 + 顶部工具条 + 最大 1460px 内容区。
- 881 至 1180px：保留侧栏，项目卡改为两列，主视觉减少装饰占比。
- 880px 以下：主导航固定为底部三项操作坞；资源配置仍从页面入口进入。
- 590px 以下：指标两列、内容卡单列、抽屉全宽、表格隐藏更新时间列。
- 页面先展示当前状态和主操作，再展示上下文列表，最后展示解释性信息。

### 交互与可访问性

- 所有输入都由真实 `label` 包裹，点击标签即可聚焦输入框。
- 键盘焦点使用 3px 品牌色外环；按钮必须有可读名称。
- 加载、成功、失败、待审批使用文字、图标和颜色共同表达。
- 弹窗点击遮罩可关闭，危险动作保留明确文字；任务详情在右侧检查器中展开。
- 尊重 `prefers-reduced-motion`，关闭非必要过渡和动画。
